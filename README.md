# Парсер вакансий с HeadHunter

Проект для поиска, анализа и управления вакансиями с платформы HeadHunter через API.

## 🚀 Возможности

- 🔍 **Поиск вакансий** по ключевым словам на HeadHunter
- 💰 **Топ-N вакансий** по зарплате
- 🔎 **Фильтрация** по ключевым словам в описании
- 💾 **Сохранение** результатов в JSON-файл
- 📊 **Сравнение вакансий** по уровню зарплаты
- 🧹 **Управление данными** - добавление, удаление, фильтрация

## 🛠 Технологии

- Python 3.7+
- requests - для работы с API
- JSON - для хранения данных
- ABC - для реализации абстрактных классов
- unittest - для тестирования

## 📁 Структура проекта

```
Coursework_2.1/
├── src/
│   ├── main.py              # Основной исполняемый файл
│   ├── vacancies.json       # Файл с сохраненными вакансиями (создается автоматически)
│   └── ...
├── tests/                   # Тесты (опционально)
├── requirements.txt         # Зависимости проекта
└── README.md               # Этот файл
```

## ⚡ Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

Или установите requests напрямую:
```bash
pip install requests
```

### 2. Запуск программы

```bash
python src/main.py
```

### 3. Запуск тестов

```bash
python -m unittest tests.py
```

## 🎮 Использование

После запуска программы вы увидите меню:

```
=== Парсер вакансий HeadHunter ===

1. Поиск вакансий на HeadHunter
2. Показать топ N вакансий по зарплате  
3. Поиск вакансий по ключевому слову в описании
4. Показать все сохраненные вакансии
5. Очистить все вакансии
0. Выход
```

### Пример работы:

1. **Поиск вакансий** - введите "Python developer" для поиска вакансий Python-разработчика
2. **Топ по зарплате** - укажите N=10 для показа 10 самых высокооплачиваемых вакансий
3. **Поиск в описании** - найдите вакансии с ключевым словом "Django" в требованиях

## 🏗 Архитектура

#### 🔌 `VacancyAPI` (Абстрактный)

## 🔧 Принципы разработки

### SOLID
- **Single Responsibility** - каждый класс имеет одну ответственность
- **Open/Closed** - легко расширить новыми API и форматами хранения
- **Liskov Substitution** - наследники полностью заменяют родителей
- **Interface Segregation** - узкоспециализированные интерфейсы
- **Dependency Inversion** - зависимости от абстракций

### Другие принципы ООП
- **Инкапсуляция** - валидация данных и скрытие внутренней реализации
- **Наследование** - иерархия классов API и менеджеров данных
- **Полиморфизм** - единый интерфейс для разных реализаций
